# 知会 · 通用办公小助手（meeting-pmo-assistant-generic）

## 🧭 小白怎么用（先看这个）

装好之后不知道怎么问？打开 [TUTORIAL.md](TUTORIAL.md)：约会议、建日程、PMO 杂事的话术直接复制发给智能体就能用，并附带「你会看到什么」的预期结果。出问题先查里面的急救表，不用找作者。

> 原名 meeting-assistant，2026-11-15 更名，旧链接自动跳转。

**一句话：你说「我想约谁谁谁开会」，它帮你写好会议卡、查忙闲、建好日程；不值得开的会，它劝你别开。**

支持飞书、钉钉、企业微信。你不用懂技术，没装技能它也会教你怎么装。

## 三步上手

1. 把本仓库交给 AI：「读 CLAUDE.md，以后按知会的方式帮我安排会议。」
2. 回答三个问题：用哪个办公平台？有没有装对应技能？想约谁谈什么？
3. 确认会议卡 → 选候选时段 → 它创建日程并回执链接。

## 它会帮你做的 PMO 杂事

- 会前 24 小时提醒补材料
- 会后行动项写回会议卡、归档
- 常设会议每月问一次「还值得开吗」
- 时间冲突时给候选时段和礼貌邀约话术

## 时长

25 / 45 / 60 分钟三选一，不选默认 60 分钟。

## 三条规矩

会议卡没确认不建日程；查不到忙闲不硬占时间；参会人没确认不发邀请。

## 不用问作者：常见问题自查

| 问题 | 答案 |
|---|---|
| 仓库是公开的吗 | 是，已公开，任何人可查看、克隆、改造 |
| 没有对应平台技能能用吗 | 先跑环境自检；没有就按指引安装，找不到技能会如实告知并给替代路径 |
| 会直接建日程/改文档吗 | 不会，先出卡片或计划，你确认后才执行；文档修改登记版本号可回退 |

| 协议 | MIT，可商用，保留署名 |

## 版本与回退

本仓库用 Git 历史作为版本索引，随时可以回到任何一个可用状态。

| 版本 | 日期 | 一句话 | 取用方式 |
|---|---|---|---|
| v1（公开首发） | 2026-11-23 | 清理个人化内容后首次公开 | `main` 分支当前 HEAD |
| 更名前 | 2026-11-15 | 原名 meeting-assistant | GitHub 自动跳转 |

回退命令（改坏了随时退回）：

```bash
git log --oneline                 # 看历史，找到想回去的那次
git checkout <commit> -- CLAUDE.md   # 只退单个文件
git checkout <commit>             # 整仓临时回看（看完 git switch - 回来）
git revert <commit>               # 撤销某次提交，保留历史
```

**回退前先备份你自己改过的配置**，尤其是 `adapters/` 里填过的平台信息。
