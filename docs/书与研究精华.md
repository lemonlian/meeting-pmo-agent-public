# 三份书/研究 → Agent 判断逻辑对照表

## 1. Patrick Lencioni《Death by Meeting》

核心：会议无聊低效，不是会议本身的错，是**结构和冲突管理**的错。

| 书中精华 | 落地成 Agent 规则 |
|---|---|
| 四类会议：日碰头 5 分钟站立、周战术 45–90 分钟、月战略每题 2 小时、季度复盘 1–2 天 | 会议卡必须先标类型，类型决定默认时长与形式 |
| 周战术会不要提前写死议程，先闪电轮再定议题 | 周会只生成「闪电轮 + 现场议题池」，不生成逐分钟议程 |
| 开场要「设钩子」：竞争威胁、错误决策的代价、对干系人的影响 | 会议卡背景段必须写「不开/开错的代价」，给参会人来开的理由 |
| 主持人要「挖掘冲突」，分歧是生产力 | 会议卡必须有「分歧点」字段，空着要退回重写 |

来源：https://capacity-building.com/library/reading-summary/death-by-meeting-book-summary/

## 2. 哈佛商学院《Is Agenda Theater Ruining Your Meetings?》(2022)

核心：员工每周花 3 小时以上写议程，但书面议程对会议质量提升并不稳定，还会制造「我已经准备好了」的错觉（自我感觉准备度 +21%）。**结果导向，而非流程导向。**

| 研究精华 | 落地成 Agent 规则 |
|---|---|
| 先问 why：这个会要达成什么 | 没有一句可验证的结果，就不允许进入建日程 |
| 自由讨论能达成，就别做复杂结构 | 议题清单保持最短，不生成逐分钟安排 |
| who：能提前单独对齐的人，不必拉进会 | 参会人分必须/可选，建议先与干系人会前单独对齐 |
| 不要过度设计 how 和 when | 默认 25/50 分钟整块，不写「第一题 10 分钟」式时间表 |

来源：https://www.hbs.edu/ris/Publication%20Files/Is%20Agenda%20Theater%20Ruining%20Your%20Meetings_b4ff576f-51fa-4cfd-8d26-f3842e5e7a0f.pdf

## 3. 《Stop the Meeting Madness》（Harvard Business Review 研究）

核心：高管每周近 23 小时开会（1960 年代不到 10 小时），仅少数会议被认为值得。会议要作为组织级资源被审计。

| 研究精华 | 落地成 Agent 规则 |
|---|---|
| 会议有真实成本，占用的是所有人的深度工作时间 | 会议卡显示「总人力成本 = 时长 × 人数」 |
| 定期清理常设会议 | recurring 会议每月复盘一次「还值得开吗」 |

来源：https://www.hbs.edu/faculty/Pages/item.aspx?num=52836

## 4. 晓莲的会议观（与书并列的第一优先级）

- **会议是为了快速解决问题，不是为了掰扯**：能提前让人想的，绝不留到会上才开始想。
- **约时间要不突兀、有礼貌，这是职业操守**：先问忙闲、给候选、说清占用、允许改期。
- 两条冲突时，以晓莲的判断为准。
