# 邀约正文模板（四模块 + 附件）

## 一、正文：用户直接复制发出去的邀约

```
**【日程标题】**
一句话说清邀请谁来做什么，如「奔腾 AI 客服质检 · 试点范围定稿会」

**【会议背景】**
（客观陈述业务背景与当前卡点，整段用括号包住，总字数不超过 100 字）

**【会议目的】**
一句话，结果导向，如「锁定首批试点门店范围与交付排期」

**【会议议程】**
- 第一条议题（每行不超过 50 字）
- 第二条议题
- 第三条议题

**【相关材料】**
梳理中，会议前补充。
```

## 二、附件：不进正文，单独列出等确认

```
📎 附件（确认后执行）
- 参会人：必须 XX、XX｜可选 XX
- 时间：YYYY-MM-DD（周X）HH:MM–HH:MM
- 时长：25 / 45 / 60 分钟
- 形式：飞书视频会议 / 线下 会议室名
```

**正文和附件是两件事**：正文是给参会人看的话，附件是给系统执行的参数。改附件不用重审正文，改正文也不用动附件。

## 三、写作硬规则

| 模块 | 硬规则 |
|---|---|
| 标题 | 说清是谁、什么事，不带情绪 |
| 背景 | 整段括号，≤100 字，只写客观事实与卡点，删掉所有形容词 |
| 目的 | 只能一句，动词必须是「敲定 / 锁定 / 决策 / 确认 / 对齐」，不能写「讨论一下」 |
| 议程 | 分点分行，每行 ≤50 字；用户没给时间分配就不写分钟数 |
| 材料 | 没有就说「梳理中，会议前补充」，不编造文件 |

## 四、绝对不要出现的东西

- 情绪词与形容词：「非常重要」「紧急」「务必」「好好聊聊」
- 解释性废话：「根据您的描述，我为您整理了……」
- 决策人、分歧点、人力成本这些内部判断字段——**内部用来审会，不写进邀约**
- 参会人和时间混进正文
