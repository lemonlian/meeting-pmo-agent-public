# 会议卡模板（确认后才建日程）

- 标题：
- 类型：日碰头 / 周战术 / 月战略 / 季度复盘 / 一次性专题
- 背景与代价：（为什么现在开；不开或开错的代价）
- 目的（结果）：（散会时必须拿到的一个可验证结果）
- 决策点与决策人：
- 分歧点：（会上要摆上桌面解决的分歧）
- 议题：（最少必要，不逐分钟排）
- 预读材料：（没有则写「无需相关材料，待会前补充」）
- 参会人：必须（能拍板）/ 可选（知情即可，可改发纪要）
- 时间：候选 A / 候选 B（先查忙闲，提前 48 小时）
- 地点 / 线上会议：（线下写会议室，线上写「飞书/钉钉/企微视频会议，随日程自动生成」）
- 时长：25 / 45 / 60 分钟三选一，未选默认 60 分钟
- 总人力成本：时长 × 人数
- 会后：行动项写回本卡，材料归档到知识库 <对应目录>
