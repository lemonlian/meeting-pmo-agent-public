# 飞书执行适配器

## 能力检测
- 优先：飞书技能（lark-calendar 等）或 `lark-cli` 已登录。
- 检测失败时给用户的安装指引：安装 `lark-cli` → 扫码登录 → 再自检。

## 忙闲
- 创建日程前，对全部参会人查忙闲（freebusy），冲突则换候选时段。
- 跨公司或无权限时，退回「候选时段 + 邀约话术」。

## 创建
- 用日历创建接口写入：标题、起止时间、参会人（必须/可选）、地点或视频会议、会议卡正文。
- 创建后回执：日程链接 + 时间 + 参会人清单。
