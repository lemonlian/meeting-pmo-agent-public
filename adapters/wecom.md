# 企业微信执行适配器

## 能力检测
- 检查企业微信官方 CLI（wecom-cli）是否可用；没有则引导安装并扫码授权日程与会议权限。

## 能力清单
- 创建 / 查询 / 更新日程（不支持修改与取消周期日程）
- 查看闲忙、约多人共同空闲时段（创建前必查）
- 添加参与人、预定 / 取消会议、订会议室与查会议室空闲

## 创建后回执
日程标题、时间、参会人、会议室或会议链接。
